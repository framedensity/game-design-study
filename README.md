# ゲーム設計 学習帳

ゲーム設計を学ぶための、自分用の静的サイトです。サーバーは不要です。

## 開き方

`index.html` をダブルクリックして、ブラウザで開くだけです。

## ファイルの構成

```
index.html        画面の骨組み（メニューなど）
css/style.css     見た目（色は先頭の :root で変えられます）
js/ruby.js        ふりがなの処理
js/store.js       学習記録と、途中のクイズの保存（ブラウザの localStorage）
js/ui.js          共通の部品（出典のリスト）
js/demos.js       動く図解（ヒットストップ、予備動作、フロー）
js/tips.js        「ひとこと」（知識・コツ・やってみよう）の表示
js/quiz.js        クイズの出題と答え合わせ
js/app.js         画面の切り替え（今日の学習／復習／進捗）
data/quiz.js      クイズの教材データ
data/tips.js      「ひとこと」の教材データ
```

教材（`data/`）と機能（`js/`）は分けてあります。問題やひとことを足したり直したりする時は、`data/` のファイルだけを編集すれば足ります。

## 学び方のしくみ

- **途中でやめても大丈夫**：答えるたびに保存されます。次に開くと「今日の学習」に「続きから」が出ます。
- **おまかせ5問**：間違えた問題 → まだ解いていない問題 の順に出ます。
- **ひとこと**：3問ごとに、「知識」「コツ」「やってみよう」のどれかが出ます（`js/quiz.js` の `TIP_EVERY` で変えられます）。
- **やってみよう**：紙・サイコロ・身の回りの物・動画などで、自分の手で試す課題です。「やった！」で記録、「あとでやる」でトップの一覧に残ります。
- **動く図解**：問題やひとことに `"demo": "hitstop"` のように書くと、答えた後に、触って確かめられる図が出ます。使える名前は `hitstop`、`anticipation`、`flow` です。新しい図は `js/demos.js` に足します（考え方を見せるための図で、ゲームの試作ではありません）。

## なぜ教材が .json ではなく .js なのか

ブラウザは、ファイルをダブルクリックで開いた時、安全のために `.json` ファイルを読み込めません。
そのため、中身は JSON と同じ形のまま、先頭に `window.GDS_DATA.quiz =` を付けた `.js` にしています。

## ふりがなの書き方

| 書き方 | 意味 |
|---|---|
| `漢字《かんじ》` | 《 の直前に続く漢字に、ふりがなを付けます |
| `｜釣り合い《つりあい》` | 送りがなを含む言葉や、範囲をはっきりさせたい時は、全角の `｜` で始まりを示します |
| `漢字《かんじ？》` | 読みに確信がない言葉。画面では点線と色で「読み未確認」と表示されます |

画面右上のボタンで、ふりがなの表示・非表示を切り替えられます。設定は保存されます。

## 問題の足し方

`data/quiz.js` の `questions` に、次の形で1問を足します。

```js
{
  "id": "q022",                 // 重ならない番号。記録はこのIDで保存されるので、後から変えない
  "category": "基本の概念",      // 同じ文字列の問題が、1つの分野にまとまります
  "question": "問題文",
  "choices": ["正解", "ちがう答え", "ちがう答え", "ちがう答え"],
  "answer": 0,                  // 正解の位置（0から数える）。表示の時は順番がシャッフルされます
  "explanation": "解説（自分の言葉で）",
  "example": "日本のゲームを使った例。自分の分析なら「（考察）」と書く",
  "sources": [
    { "text": "出典の説明", "url": "https://...", "status": "確認済み" }
  ]
}
```

`status` は次の3つのどれかにします。

- `確認済み`：書誌や講演の存在を確かめたもの
- `未確認`：まだ確かめていないもの
- `出典なし`：一般的な用語や考え方で、特定の出典がないもの

## 教材のルール

- 本の文章をそのまま写さない。概念は自分の言葉でまとめて、出典を付ける。
- 確認できていないことは、「未確認」と書く。
- 解説では、日本のゲームや日本の作り手の例を中心に使う。

## 記録について

- 間違えた問題は「復習」に入ります。あとで正解すると、リストから外れます。
- 記録は、このブラウザの中だけに保存されます。別のブラウザやPCで続ける時は、「進捗」画面で書き出して、読み込んでください。
